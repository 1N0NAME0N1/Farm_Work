# Farm jobs tracker Implementation Plan

> **For agentic workers:** Native execution in this session.

**Goal:** Build a personal browser app to manage Genshin and Wuthering Waves farming jobs and monthly income.

**Architecture:** Static HTML with CSS and JavaScript; localStorage is the only persistence. Job income is the sum of dated updates, grouped by update month.

**Tech Stack:** HTML, CSS, vanilla JavaScript, localStorage.

**Spec:** `docs/superpowers/specs/2026-11-05-farm-jobs-design.md`

## Global Constraints

- No third-party dependencies or server.
- Keep data in the user's current browser profile.
- Provide separate game views and a monthly income dashboard.

## Review Focus

- Empty and malformed storage: recover to an empty job list without breaking rendering.
- Amount validation: reject negative or non-finite income.
- Month boundaries: group update entries by local calendar month.
- Deleting a job: remove only the selected job.
